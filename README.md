Bank Loan Customer Analysis

Project Overview
The Bank Customer Analysis project focuses on analyzing banking customer data to understand customer demographics, financial activities, and loyalty classifications. The objective is to extract meaningful business insights using data analytics tools and present them through interactive dashboards.

Tools & Technologies
- Python (Pandas): Data cleaning and preprocessing.
- MySQL: Data analysis using SQL queries.
- Microsoft Excel: Pivot tables, charts, slicers, and interactive dashboard.
- Power BI: Data visualization, DAX measures, and interactive dashboard development.

Project Workflow

 1. Python – Data Cleaning
- Loaded and explored the banking dataset.
- Checked for missing values and duplicate records.
- Identified repeated customer IDs.
- Converted date columns into appropriate formats.
- Cleaned and prepared the dataset for analysis.

 2. SQL – Data Analysis
- Performed customer data analysis using SQL.
- Analyzed customer demographics and financial information.
- Calculated key metrics and aggregate values.
- Used SQL queries to extract meaningful business insights.

 3. Excel – Dashboard Development
- Created an interactive banking customer dashboard featuring:

  Key Performance Indicators (KPIs):
- Total Customers
- Average Age
- Average Income
- Total Bank Deposits
- Total Bank Loans

  Visualizations:
- Customers by Occupation
- Customers by Age Group
- Customers by Nationality
- Customers by Loyalty Classification
- Customers by Gender

  Interactive Features:
- Slicers for Occupation, Age, Nationality, Loyalty Classification, and Gender.

 4. Power BI – Dashboard Development
- Imported and transformed banking customer data.
- Created DAX measures for key performance indicators.

  Developed interactive visualizations.
- Designed an interactive dashboard to explore customer demographics and financial metrics.
- Dataset Summary
- Total Records: 3,000
- Unique Customer IDs: 2,940
- Repeated Customer IDs: 60
- Completely Duplicate Rows: 0

Project Objectives
- Understand customer demographics.
- Analyze customer financial profiles.
- Explore customer loyalty classifications.
- Identify patterns in banking deposits and loans.
- Build interactive dashboards for business insights.

Conclusion
- This project demonstrates practical data analytics skills, including data cleaning, SQL querying, data analysis, and dashboard development using Python, MySQL, Excel, and Power BI.
